# Paper

*AI Praises Gandhi. Would It Arrest Him? Condemned as observer, chosen as judge: the ethics of
language models tested on fifteen historical decisions.* Chrystian Schutz, September 2026. [PDF](main.pdf), 38 pages.

| File | Contents |
|---|---|
| `main.tex` | The manuscript |
| `refs.bib` | Bibliography |
| `sources.tex` | Historical sources of the case bank, generated by `scripts/make_sources_bib.py` |
| `cases.tex` | Appendix: the fifteen cases, original five-model cohort |
| `results_appendix.tex` | Appendix: law-side counts for every case, role, hindsight cell and model, generated by `scripts/make_appendices.py` |
| `figures/` | Figures generated from `results/extended/` and `results/abliteration/` (PDF for LaTeX, PNG for viewing) |

## Analysis scopes

| Input | Scope | Do not confuse with |
|---|---|---|
| `results/` | Original five models: 6,450 bank sessions, 75 dialogues | A second, disjoint cohort |
| `results/extended/` | Twelve models, including the original five and two GPT-6 successors: 17,630 bank sessions, 180 dialogues | Twelve independent model families |
| `results/abliteration/` | Two related local builds: 3,440 bank sessions, 30 dialogues | An isolated causal intervention on refusal |

The case appendix and the numerical appendix cover the original five-model scope; the main text
reports the later studies explicitly.

## Rebuild

From the repository root. None of these steps calls a model.

```bash
uv run python scripts/check_claims.py                          # 383 quoted counts
uv run python scripts/make_tables.py                           # results/tables.md
uv run --with matplotlib python scripts/make_extended_figures.py
uv run --with matplotlib python scripts/make_blog_figures.py --paper
uv run python scripts/make_sources_bib.py
uv run python scripts/make_appendices.py
cd paper && tectonic -X compile main.tex
```

`scripts/check_claims.py` recomputes every count the ledger lists from the aggregate tables and
checks that each quoted sentence is still present in the manuscript, the case appendix or the
interactive page. Prose outside the ledger is not covered by it. When a number in the text
changes, change the ledger in the same commit.

The aggregates themselves were built from the raw Inspect logs by `scripts/aggregate_results.py`
(`--extended`, `--abliteration`). Those logs are not published; the per-sample transcripts derived
from them are in the [Hugging Face dataset](https://huggingface.co/datasets/chrystians/canon-historical-ethics).

For an arXiv submission, bundle `main.tex`, `refs.bib`, `cases.tex`, `results_appendix.tex`,
`sources.tex` and `figures/*.pdf`.
